# Java Assignment 4 – Event-Driven GUI Design

## Assignment Overview

**Course:** Programming in Java  
**Assignment:** Assignment 4 – CO4  
**Topic:** Event-Driven GUI Design  
**Language:** Java  
**GUI Technology:** AWT and Swing  
**Database:** MySQL and JDBC  

## Description

This assignment focuses on designing and implementing event-driven graphical user interfaces using Java AWT and Swing.

It covers event handling, GUI components, layout managers, listener interfaces, application design, database connectivity, validation and GUI responsiveness.

The assignment follows the workflow:

**Interpret → Identify → Design → Implement → Trace → Challenge → Refine**

## Tasks Included

| Task | Title | Description |
|---|---|---|
| Task 01 | GUI Design Review | Student fee-payment application design and event handling. |
| Task 02 | Requirement to Event-Driven Design | Hospital appointment booking system using Swing events. |
| Task 03 | From Sketch to Layout | Campus library search interface using layout managers. |
| Task 04 | Event-Handling Forensics | Mouse events, drawing points and repainting. |
| Task 05 | Same Screen, Different Event Styles | Currency converter using four event-handling approaches. |
| Task 06 | Design Challenge | Campus event-registration system using Swing and MySQL. |

## Learning Outcomes

- Understand event-driven programming in Java.
- Identify event sources, event objects and listener interfaces.
- Design user interfaces using Swing components.
- Apply suitable layout managers.
- Implement different event-handling techniques.
- Validate user input and handle exceptions.
- Separate presentation, service and database logic.
- Connect Java applications to MySQL using JDBC.
- Improve GUI responsiveness using SwingWorker.

## How to Run

1. Install JDK 8 or later.
2. Open the required task folder in VS Code or another Java IDE.
3. Compile the required Java files.
4. Run the main Java class of the task.
5. For Task 06, configure MySQL and add MySQL Connector/J before running the application.

## Conclusion

This assignment provides practical experience in Java event-driven GUI development. It demonstrates how to design user-friendly interfaces, handle events, apply layout managers, validate inputs and connect desktop applications to databases.
